# 🎨 AI Social Studio

> Transform your media into ready-to-post social content with AI

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📤 **Media Upload** | Drag & drop images/videos |
| ✍️ **AI Captions** | Generate captions & hashtags |
| 🖼️ **Image Editing** | Text-based AI modifications |
| ⚡ **Enhancement** | Improve quality & clarity |
| 📱 **Social Posting** | Post to Instagram/YouTube |

---

## 🚀 Quick Start

```bash
# Clone & install
git clone https://github.com/rajeevmps/ai-media-uploader.git
cd ai-media-uploader
npm install

# Run locally
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

---

## 🛠️ Tech Stack

- **Frontend:** React 19 + Vite
- **Styling:** CSS Modules + Glassmorphism
- **Backend:** n8n (workflow automation)
- **AI:** OpenAI, Stability AI
- **Deploy:** Vercel
